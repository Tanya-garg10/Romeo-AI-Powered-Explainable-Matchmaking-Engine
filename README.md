# ❤️ Romeo – AI-Powered Explainable Matchmaking Engine

> Beyond Matching. Towards Meaningful Compatibility.

Romeo is an AI-powered matchmaking platform built for a hackathon. Unlike traditional dating platforms that rely only on similarity scores, Romeo combines intelligent filtering, weighted compatibility analysis, and explainable AI reasoning to recommend the most compatible match.

To make matchmaking more engaging, Romeo introduces **Parallel Hearts**—an innovative feature that simulates alternate relationship futures, helping users explore how compatibility changes under different life scenarios.

## 🚀 Features

### 🎯 Intelligent Matchmaker Engine

- Load and analyze multiple user profiles
- Smart filtering using:
  - Age preferences
  - Gender preferences
  - Relationship goals
  - Lifestyle compatibility
  - Deal-breakers
- Weighted compatibility scoring
- Top 10 match recommendations
- Detailed compatibility analysis
- AI-generated Pros & Cons
- Trade-off analysis
- Explainable reasoning
- Final Best Match selection with justification

### 🌌 Parallel Hearts

**The Inevitable Evolution**

Parallel Hearts is Romeo's signature innovation.

Instead of only recommending a partner, Romeo simulates multiple relationship futures to help users understand long-term compatibility.

Each simulation generates:

- 🏡 Same City Timeline
- ✈️ Long Distance Timeline
- 💼 Career Relocation Timeline

For every timeline Romeo predicts:

- Communication
- Trust
- Conflict Level
- Emotional Growth
- Success Probability
- AI-generated explanation

## 📊 Compatibility Factors

Romeo evaluates compatibility using multiple weighted factors:

- ❤️ Shared Interests
- 🧩 Personality Compatibility
- 🎯 Relationship Goals
- 🌱 Core Values
- 🏡 Lifestyle Habits
- 💬 Communication Style
- 🚫 Deal-breakers

Instead of simply selecting the highest score, Romeo compares the strongest candidates and explains **why** one match is recommended over another.
